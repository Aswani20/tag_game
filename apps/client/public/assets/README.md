# Presentation assets

The title landscape in `menu-garden.svg`, runner portraits and wordmark are original vector drawings.
The Phaser scene uses the same runner drawing as the menu, rasterized once per headband color.
Map scenery is painted once per map selection and cached as a render texture. Dust and impact effects
are limited to 48 particles. Sound cues are synthesized with Web Audio after a user gesture.
The interface uses installed system fonts. There are no external art, font or audio downloads.
